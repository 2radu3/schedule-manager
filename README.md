# Schedule Manager

A lightweight, desktop-based timetable and schedule management application built with C# and Windows Forms (.NET). Designed to help users organize, view, and track daily or weekly schedules through an intuitive graphical interface.

---

## Features

- **Intuitive GUI**: Clean desktop interface designed with Windows Forms for quick navigation and timetable editing.
- **Schedule Management**: Add, update, and manage timetable entries (classes, meetings, or recurring tasks).
- **Data Organization**: Structured backend classes to handle schedule entities and persistent state.
- **Lightweight & Fast**: Minimal dependencies, running natively on Windows with rapid startup times.

---

## Tech Stack

- **Language**: C#
- **Framework**: .NET (Windows Forms)
- **IDE / Build System**: Visual Studio / MSBuild (`.slnx` solution format)
